# Website Wisata Taman Keliling Dunia Majalengka

## Deskripsi
Website ini dibuat untuk memenuhi tugas mata kuliah Pengembangan Aplikasi Berbasis Web. Website ini bertujuan untuk memperkenalkan objek wisata Taman Keliling Dunia yang berada di Majalengka, Jawa Barat.

## Fitur Website
- Beranda
- About
- Fasilitas Wisata
- Harga Tiket
- Paket Tambahan
- Gallery foto dan video
- Lokasi wisata dan Google Maps

## Teknologi yang Digunakan
- HTML
- CSS

## Struktur Folder
- `index.html` — halaman utama website
- `style.css` — mengatur tampilan website
- `img/` — menyimpan gambar dan foto wisata
- `video.mp4/` — menyimpan video wisata

## Cara Menjalankan
Buka file `index.html` menggunakan browser untuk melihat website.
